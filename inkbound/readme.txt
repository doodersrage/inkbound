Serialized fiction tools for WordPress: stories, chapter management, reader follows, update mail, and reading progress.

== Description ==

WordPress can host a blog. It cannot, natively, host a Royal Road / Substack-style serial.

Inkbound adds:

* Stories and numbered chapters (with TOC, scheduling, author's notes)
* Reader follows and email subscriptions
* Update notifications when a chapter publishes (on-site inbox + mail)
* Reading progress and continue-reading for guests and accounts
* A dedicated catalog and chapter reader

== Installation ==

1. Upload the `inkbound` folder to `wp-content/plugins/`
2. Activate Inkbound
3. Create a Story, then add Chapters from the story editor
4. Optional: Inkbound → Settings to put the catalog on the homepage
